# File Management

Use `path_info`, `list_directory`, `search_filename` or `start_search` to locate files. Read relevant content before editing. Use `create_project_backup` before bulk modifications, `edit_block` for surgical edits and `checksum_sha256` to verify transfers. Do not delete, overwrite, or move unrelated files. Respect user-specified project boundaries. Prefer paginated reads for large files. Avoid collecting passwords, keys or private data not needed for the task.
