# Audit And Usage

Use `get_usage_stats`, `get_recent_tool_calls`, `list_remote_tool_calls`, `get_tool_result` and `review_device_call` for evidence. Keep result summaries concise and separate attempted actions from verified completions. Local tool usage does not establish ChatGPT or ngrok billing. Do not save secrets with `keep_tool_result` or `track_ui_event`.
