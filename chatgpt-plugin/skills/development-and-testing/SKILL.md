# Development And Testing

Read the project instructions, Git status, and relevant files before modifying. Create a backup or branch before substantial changes. Use incremental patches, run relevant unit tests, and inspect exit codes. Do not claim 100% completion until acceptance criteria and end-to-end tests pass. Preserve user data and environment files. Do not enable auto-deploy or auto-publish without permission.
